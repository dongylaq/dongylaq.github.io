# Yulong Dong Homepage

This repository contains the source for [dongylaq.github.io](https://dongylaq.github.io), built with the [al-folio](https://github.com/alshedivat/al-folio) Jekyll theme.

## Local build

al-folio v1.x requires Ruby 3.2 or newer. With a compatible Ruby installed:

```sh
bundle install
npm install
./bin/preview
```

The deploy workflow builds the site on GitHub Actions with Ruby 3.3.5.
